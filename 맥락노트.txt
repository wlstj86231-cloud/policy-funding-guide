━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    - 사이트 어디에도 보험·금융상품 권유 문구 사용 금지

2. API 연동 구조 설명 (30~33번 작업 전 필독)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  왜 브라우저에서 직접 API를 못 부르나?
    브라우저 보안 규칙(CORS) 때문이다.
    "A 사이트가 B 사이트 데이터를 직접 가져오면 안 된다"는 규칙.
    정부 API 서버가 이 허가를 내주지 않는다.

  해결책: 기존 policyfund-api의 동일 출처 API

    [policyfundpedia.com] -> [/api/bizinfo] -> [기업마당 API]

  별도 bizinfo-proxy Worker는 사용하거나 다시 만들지 않는다.
  worker/src/index.js가 /api/bizinfo만 가로채고,
  worker/src/bizinfo.js가 입력 제한·캐시·속도 제한·응답 검증을 담당한다.

  Cloudflare Workers 특징:
    - 기존 policyfund-api 한 곳에서 운영
    - API 키는 BIZINFO_API_KEY secret으로만 보관
    - 성공 응답 캐시와 상류 호출 속도 제한 적용
    - workers.dev에서 /api/bizinfo 사용 차단

  기업마당 API 정보:
    주소: https://apis.data.go.kr/1421000/mssBizService_v2/getbizList_v2
    제공: 전국 정부·지자체 지원사업 공고
    업데이트: 실시간 (새 공고 즉시 반영)
    비용: 무료 (공공데이터포털 API 키 필요)

  API 파라미터:
    serviceKey  -> 공공데이터포털 발급 인증 키
    numOfRows   -> 한 번에 가져올 공고 수 (화면 15, 최대 30)
    pageNo      -> 페이지 번호 (1~1000, 1 = 가장 최신)
    분야 분류   -> 현재 사용 중인 상류 API가 지원하지 않으므로 제공하지 않음

  응답 데이터 주요 항목:
    title                -> 공고 제목
    viewUrl              -> 공고 상세 주소
    dataContents         -> 공고 요약
    applicationStartDate -> 신청 시작일
    applicationEndDate   -> 신청 마감일
    writerName           -> 작성 기관

  기업마당 API 키 발급 방법:
    1. https://www.data.go.kr 접속 -> 로그인
    2. "중소기업지원사업목록" 검색
    3. "중소벤처기업부_중소기업지원사업목록" 클릭
    4. "활용신청" -> 목적 입력 -> 신청
    5. 1~2시간 후 마이페이지 -> 오픈API -> 인증키(Encoding) 복사
    주의: 이 키는 절대 깃에 올리지 않는다.
