════════════════════════════════════════
[규칙 1] 작업 시작 전 읽는 순서
════════════════════════════════════════

  매번 작업 전 아래 3개 파일을 순서대로 읽는다:
    1번째 → 이 파일 (규칙서)
    2번째 → 계획서_아키텍쳐.txt
    3번째 → 체크리스트_업데이트로그.txt

════════════════════════════════════════
[규칙 2] 한 번에 딱 하나만 한다
════════════════════════════════════════

  "17번 해줘" 라고 하면 → 17번만 한다.
  시키지 않은 코드는 절대 건드리지 않는다.

════════════════════════════════════════
[규칙 3] 완료 체크 방법
════════════════════════════════════════

  "17번 완료" 라고 하면:
  → 체크리스트_업데이트로그.txt 에서 [ ] 17. → [v] 17. 로 바꾼다.
  → 바뀐 전체 내용을 사용자에게 보여준다.

════════════════════════════════════════
[규칙 4] 오류가 생겼을 때
════════════════════════════════════════

  코드를 고쳤을 때 → 체크리스트 맨 아래 오류 로그에 기록한다.
  형식: [날짜] 문제: ___ / 해결: ___ (2줄 이내)

════════════════════════════════════════
[규칙 5] 깃 푸시 규칙
════════════════════════════════════════

  작업이 끝날 때마다 자동 푸시:
    git add .
    git commit -m "작업 내용 요약"
    git push

  깃에 절대 올리면 안 되는 파일:
    - 필수_행동강령_cli.txt
    - 계획서_아키텍쳐.txt
    - 맥락노트.txt
    - 체크리스트_업데이트로그.txt
    - bizinfo-proxy.js  ← API 키 포함, 절대 금지
