# 개인정보처리방침

정책자금 백과 Android 앱은 회원가입, 로그인, 결제, 위치정보 수집 기능을 제공하지 않습니다.

## 수집하는 정보

앱 운영자가 직접 수집하는 개인정보는 없습니다.

## 기기 내부 저장 정보

사용자가 관심 정책자금을 저장하면 해당 정책자금 ID 목록이 사용자의 기기 내부 저장소에만 저장됩니다. 이 정보는 외부 서버로 전송되지 않습니다.

## 외부 링크

앱은 정책자금 공식 기관 사이트와 `policyfundpedia.com`으로 연결되는 외부 링크를 제공합니다. 외부 사이트 이용 시에는 해당 사이트의 개인정보처리방침이 적용됩니다.

## 문의

앱 관련 문의는 `policyfundpedia.com` 사이트 운영자에게 문의합니다.
